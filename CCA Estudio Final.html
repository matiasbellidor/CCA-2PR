Ejercicio 1 · Métricas (20 pts)

Datos: ID 1 → (Y=1; 0,80) · ID 2 → (0; 0,70) · ID 3 → (1; 0,65) · ID 4 → (0; 0,45) · ID 5 → (0; 0,20)

1) Matriz de confusión con threshold 0,6

Regla: se predice 1 (mora) si Y_PRED ≥ 0,6.

IDY_TRUEY_PREDClase predichaResultado
110,801TP
200,701FP
310,651TP
400,450TN
500,200TN
                  Predicho 1     Predicho 0
Real 1 (mora)     TP = 2         FN = 0
Real 0 (no mora)  FP = 1         TN = 2

2) Accuracy, precision, recall

Accuracy  = (TP+TN)/N   = (2+2)/5 = 0,80
Precision = TP/(TP+FP)  = 2/(2+1) = 0,667
Recall    = TP/(TP+FN)  = 2/(2+0) = 1,00

Interpretación: el modelo detecta a todos los morosos (recall 100%) pero
1 de cada 3 alertas es falsa (precision 66,7%).

3) Costo FN = 10 × costo FP: ¿qué hacer con el threshold?

Hay que BAJAR el threshold: un FN (moroso no detectado) sale 10 veces más caro
que un FP, entonces conviene predecir "mora" con menos evidencia, aceptar más
FP y ganar recall (TPR).
Regla de decisión con costos: predecir 1 si p ≥ C_FP/(C_FP + C_FN) = 1/(1+10) ≈ 0,09.
Costo total = C_FN·FN + C_FP·FP. Se elige el umbral que lo minimiza.
Nota: en esta muestra con 0,6 ya hay FN = 0; bajar más solo sumaría FP.

4) ¿A qué métrica darle más importancia?

Al RECALL (sensibilidad, TPR = TP/(TP+FN)): mide qué proporción de los morosos
reales se detecta, y el error caro es el FN. Accuracy no sirve: no distingue
tipos de error y se engaña con clases desbalanceadas. Precision se vigila como
restricción para no inundar de falsas alarmas (F1 o F2 como resumen).

5) Curva para TPR vs FPR

Curva ROC: grafica TPR = TP/(TP+FN) (eje Y) contra FPR = FP/(FP+TN) (eje X)
para TODOS los thresholds posibles. Muestra el trade-off sensibilidad vs falsas
alarmas sin fijar un umbral. Se resume con el AUC (1 = perfecto, 0,5 = azar).
Acá: puntos (FPR,TPR) = (0;0) (0;0,5) (0,33;0,5) (0,33;1) (0,67;1) (1;1) → AUC = 5/6 ≈ 0,83.
El punto del threshold 0,6 es (FPR; TPR) = (0,33; 1).
Ejercicio 2 · Verdadero o Falso (20 pts)
1. FALSO. Overfitting = error BAJO en entrenamiento y ALTO en test: el modelo
   memoriza el ruido y no generaliza. La afirmación está al revés.
2. VERDADERO. Feature engineering transforma y crea variables (imputar, binning,

3. VERDADERO. IA ⊃ ML ⊃ deep learning. Deep learning es el ML basado en redes

4. FALSO. Más profundidad = más hojas y más complejidad: el árbol se ajusta al
   ruido (baja el sesgo, sube la varianza) y AUMENTA el riesgo de overfitting.
   Se reduce limitando la profundidad o podando.
5. VERDADERO. PCA genera componentes ortogonales (no correlacionados), cada uno
   maximiza la varianza que queda sin explicar por los anteriores (Σv = λv).

Ejercicio 4 · Árbol de decisión (30 pts)

Variables: Historial_Reclamos (HR) · Poliza_Vida (PV) · target Riesgo_Alto: 3 Sí y 4 No (7 filas).

1) Raíz con Gini

G(nodo) = 1 − Σ p_k²          TGI = Σ (n_h/n) · G_h       → raíz = menor TGI

Padre: 3 Sí, 4 No → G = 1 − (3/7)² − (4/7)² = 24/49 = 0,490

Corte por Historial_Reclamos:
  HR = Sí (4 filas: 1 Sí, 3 No): G = 1 − (1/4)² − (3/4)² = 0,375
  HR = No (3 filas: 2 Sí, 1 No): G = 1 − (2/3)² − (1/3)² = 0,444
  TGI(HR) = 4/7·0,375 + 3/7·0,444 = 0,405

Corte por Poliza_Vida:
  PV = Sí (4 filas: 3 Sí, 1 No): G = 1 − (3/4)² − (1/4)² = 0,375
  PV = No (3 filas: 0 Sí, 3 No): G = 1 − 0 − 1 = 0   (hoja pura)
  TGI(PV) = 4/7·0,375 + 3/7·0 = 0,214

TGI(PV) = 0,214 < TGI(HR) = 0,405  →  la RAÍZ es Poliza_Vida
(ganancia = 0,490 − 0,214 = 0,276).

2) Cómo continuar

- Rama PV = No: 3 filas, todas "No" → G = 0 → HOJA pura: predice Riesgo_Alto = No.
- Rama PV = Sí: 4 filas (3 Sí, 1 No), G = 0,375, impura → se repite el proceso
  SOLO con esas filas y las variables restantes (recursive binary splitting,
  top-down y greedy):
    HR = Sí → {No, Sí}: G = 0,5     HR = No → {Sí, Sí}: G = 0
    TGI = 2/4·0,5 + 2/4·0 = 0,25 < 0,375 → el corte mejora, se hace.
  Hoja HR = No → "Sí" (pura). Hoja HR = Sí → 1 Sí / 1 No (empate, sin más variables).
- Se corta cuando el nodo es puro, no quedan variables, o se llega a un criterio
  de parada (profundidad máxima, mínimo de observaciones por hoja, mejora mínima).
- Cada hoja predice la moda (clasificación).

3) ¿Cuándo usar pruning?

Cuando el árbol quedó muy grande y hace OVERFITTING: error de entrenamiento casi 0
pero error de test/CV alto (alta varianza), hojas con muy pocas observaciones
(como este árbol de 7 filas) o muchas variables ruidosas. Se hace un
post-pruning: crecer el árbol y podar minimizando RSS(T) + α·|T| (con |T| =
cantidad de hojas), eligiendo α por validación cruzada. El pre-pruning corta
antes con hiperparámetros (max_depth, min_samples_leaf, ...). Poda → árbol más
simple, menos varianza, más fácil de interpretar.

Recetas: “si te piden X, hacé Y”

Cada receta es el paso a paso mínimo, en el orden en que se escribe en la hoja.

📊 “Calculá la matriz de confusión con threshold t”
1. Regla: ŷ = 1 si score ≥ t→2. Clasificá cada fila→3. Comparás con Y_TRUE→4. Contás TP, FP, TN, FN
  • TP: real 1 y predije 1 · FP: real 0 y predije 1 · TN: real 0 y predije 0 · FN: real 1 y predije 0.
  • Chequeo: TP+FN = total de positivos reales; FP+TN = total de negativos; todo suma N.
  • Mnemotecnia del reloj al revés: la 1ª letra (T/F) dice si acerté; la 2ª (P/N) dice lo que predije.
  • Es “≥” (si el score es igual al umbral, se predice 1) salvo que el enunciado diga “mayor que”.
📏 “Calculá accuracy, precision y recall” (y las demás)
Accuracy  = (TP+TN)/N                 → % de aciertos
Precision = TP/(TP+FP)                → de lo que marqué 1, cuánto era 1
Recall    = TPR = TP/(TP+FN)          → de los 1 reales, cuántos agarré
Especificidad = TN/(TN+FP)            FPR = FP/(FP+TN) = 1 − especificidad
F1 = 2·P·R/(P+R) = 2TP/(2TP+FP+FN)    (media ARMÓNICA)
  • Precision mira la columna “predicho 1”; recall mira la fila “real 1”.
  • Siempre cerrá con una frase: “detecta X% de los casos, pero Y% de las alertas son falsas”.
💸 “Costo de FN es k veces el de FP: ¿qué hacés con el umbral? ¿Qué métrica?”
  • FN más caro → BAJAR el umbral (más positivos: sube recall, suben los FP, baja precision). FP más caro → SUBIR.
  • Métrica prioritaria: la que controla el error caro. FN caro → recall. FP caro → precision. Accuracy casi nunca (desbalance y costos distintos).
  • Umbral óptimo teórico: t* = C_FP/(C_FP + C_FN) (k = 10 → 1/11 ≈ 0,09). En la práctica: probar umbrales y minimizar C_FN·FN + C_FP·FP.
  • Justificación en una línea: “el costo esperado de no detectar supera al de una falsa alarma, por eso acepto más FP a cambio de recall”.
📈 “¿Qué curva usarías?” · ROC, PR y AUC
PreguntaCurvaEjes
Relación entre TPR y FPR / trade-off sensibilidad vs falsas alarmasROCX = FPR · Y = TPR
Clases muy desbalanceadas / importa la clase positivaPrecision-RecallX = recall · Y = precision
  • Cada punto = un umbral. Umbral alto → esquina (0,0); umbral bajo → esquina (1,1).
  • Construcción: ordená scores de mayor a menor; en cada umbral calculá TP, FP → (FP/N, TP/P). Empezás en (0,0).
  • AUC: 1 = perfecto · 0,5 = azar (diagonal) · <0,5 ordena al revés. Interpretación: probabilidad de que un positivo al azar tenga más score que un negativo al azar. No depende del umbral.
  • Con desbalance, la ROC luce optimista (los muchos TN achican el FPR): por eso PR. Base de la PR = prevalencia.
🌲 “Elegí la raíz con Gini” (o entropía)
1. G padre→2. Por cada variable: G de cada rama→3. TGI = Σ n_h/n · G_h→4. Raíz = MENOR TGI
G = 1 − Σ p_k²     (puro = 0; máximo binario = 0,5)
TGI = Σ (n_h/n)·G_h
Con entropía: D = −Σ p_k·log2 p_k (puro 0, máx binario 1); IG = D(padre) − Σ (n_h/n)·D_h → MAYOR IG
  • Variable numérica: ordená los valores y probá los puntos medios entre consecutivos (corte “< s”).
  • Ponderás por tamaño de hoja: una hoja de 1 observación no pesa como una de 50.
  • Escribí siempre las cuentas de cada rama (cantidad de Sí/No) antes del Gini.
🌿 “¿Cómo continuás? ¿Cuándo parás? ¿Cuándo podás?”
  • Continuar: cada rama impura se trata como un problema nuevo con SUS filas: calcular TGI de las variables restantes, elegir el menor, repetir. Es top-down y greedy (mejor corte de ese paso, sin mirar hacia adelante).
  • Parar: nodo puro · sin variables · profundidad máxima · mínimo de observaciones por hoja o por partir · mejora de impureza mínima.
  • Hoja: moda (clasificación) / media (regresión).
  • Pruning: cuando hay overfitting (train ≈ 0, test alto), hojas diminutas, árbol enorme. Post-pruning: RSS(T) + α·|T|, α por cross-validation. Pre-pruning: hiperparámetros.
🌳 “Árbol de regresión: RSS”
Para cada corte (variable j, punto s): regiones R1 = {X_j < s}, R2 = {X_j ≥ s}
RSS = Σ_(i∈R1) (y_i − ȳ_R1)² + Σ_(i∈R2) (y_i − ȳ_R2)²   → gana el MENOR RSS
Predicción en cada hoja = media de y de esa hoja.
⚡ “AdaBoost: clasificá con los stumps” (voto ponderado)
1. Evaluá cada condición→2. cumple = +1 / no cumple = −1→3. α·f→4. F = Σ α·f→5. signo(F)
  • F > 0 → clase +1 · F < 0 → clase −1. Interpretá con la etiqueta del enunciado.
  • Cuidado con la polaridad: leé qué significa +1 y −1 (acá +1 = riesgo alto).
  • Trampa: dato con signo contrario (“<” vs “>”) o variable categórica con “Sí/No” invertida.
⚖️ “AdaBoost: calculá α y reponderá los pesos”
1) w_i = 1/N
2) ε = suma de pesos de los MAL clasificados
3) α = ½·ln((1−ε)/ε)
4) mal clasificado: w·e^(+α)     bien clasificado: w·e^(−α)
5) normalizar: dividir cada peso por la suma de todos
Chequeo: tras normalizar, los mal clasificados suman exactamente 0,5.
  • ε = 0,5 → α = 0 (no vota) · ε < 0,5 → α > 0 · ε > 0,5 → α < 0 (voto invertido).
  • Por qué sube el peso de los errores: para que el próximo stump se concentre en lo que el anterior erró.
🌲🌲 “Random Forest”: qué te preguntan siempre
  • Construcción: B muestras bootstrap (con reemplazo, tamaño n) → B árboles profundos sin podar → en cada nodo se eligen m ≈ √p variables al azar → voto mayoritario (promedio en regresión).
  • Por qué funciona: el promedio de árboles decorrelacionados baja la varianza sin subir el sesgo.
  • OOB: P(una observación NO entra al bootstrap) = (1−1/n)ⁿ → 1/e ≈ 0,368 (≈ 1/3). El error OOB se calcula con esas observaciones, sin necesidad de test aparte.
  • RF vs AdaBoost: RF → árboles grandes, independientes, en paralelo, voto igual. AdaBoost → stumps, secuenciales, cada uno corrige al anterior, voto con α.
🔻 “PCA: describí / calculá”
1. Sacá target e ID→2. Estandarizá (z)→3. Matriz de correlación Σ→4. Autovalores/autovectores→5. PVE = λ/Σλ→6. Elegí componentes
  • Autovector = dirección (loadings); autovalor = varianza de esa componente. Σv = λv, vᵀv = 1.
  • 2×2: λ² − traza·λ + det = 0. Con correlación r: λ = 1 ± r.
  • Cuántas: 80–85% acumulado o codo del scree plot. Máximo p componentes, ortogonales.
  • Límites: solo estructura lineal y variables cuantitativas; las componentes son menos interpretables.
🎯 “K-Means: hacé una iteración”
1. Distancia de cada punto a cada centroide→2. Asignar al más cercano→3. Centroide = promedio del grupo→4. Repetir hasta que no cambie
  • Distancia euclidiana d = √Σ(x_j − μ_j)². Podés comparar distancias al cuadrado (da lo mismo).
  • WCSS = Σ distancias² al centroide. Elegís K con el codo o la silueta s = (b−a)/máx(a,b).
  • Estandarizá antes. Sensible a outliers y a la inicialización (varias corridas).
📐 “Regresión lineal: a mano e interpretación”
β1 = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²     β0 = ȳ − β1·x̄
RSS = Σ(y−ŷ)²   TSS = Σ(y−ȳ)²   R² = 1 − RSS/TSS   RSE = √(RSS/(n−2))
SE(β1) = RSE/√Σ(x−x̄)²           t = β1/SE(β1) ~ t(n−2)     IC95% ≈ β1 ± 2·SE
  • β1: cambio esperado en Y por +1 en X (múltiple: con las otras variables fijas). R²: % de varianza explicada.
  • Test t con p-valor chico → hay evidencia de relación. R² alto no implica causalidad.
  • Fallas y remedios: no linealidad (transformar X, polinomios) · heterocedasticidad (log Y) · outliers/leverage · multicolinealidad (VIF > 5–10 → sacar variable o PCA).

Teoría unificada

Todos los temas, en el orden en que se conectan. Buscá una palabra o abrí el tema.

0 · Marco de ML: supervisado, overfitting, sesgo-varianza
  • IA ⊃ Machine Learning ⊃ Deep Learning ⊃ IA generativa. No son sinónimos. DL = redes neuronales multicapa; árboles, regresión, K-Means son ML sin ser DL.
  • Supervisado: hay variable respuesta Y etiquetada (clasificación o regresión). No supervisado: no hay Y; busca estructura (clustering, PCA).
  • Y = f(X) + ε. Error esperado = reducible (f − f̂)² + irreducible Var(ε). Un modelo no puede bajar de Var(ε).
  • Train / validation / test: train ajusta parámetros · validation elige hiperparámetros o modelo · test se usa una vez al final para estimar el error real. Validación cruzada (k-fold) cuando hay pocos datos.
  • Overfitting: error de entrenamiento BAJO y de test ALTO (varianza alta, memoriza ruido). Underfitting: ambos altos (sesgo alto). Al subir la flexibilidad el sesgo baja y la varianza sube: el error de test tiene forma de U.
  • Cómo se combate el overfitting: más datos, modelo más simple, poda, regularización, CV, ensambles, menos variables.
  • Data leakage: información del test o del futuro entra al entrenamiento (imputar o escalar con todo el dataset; una variable que “contiene” al target). Da métricas falsamente buenas.
1 · Métricas de clasificación y regresión
Predicho 1Predicho 0
Real 1TPFN
Real 0FPTN
  • Accuracy (TP+TN)/N · Precision TP/(TP+FP) · Recall/TPR/sensibilidad TP/(TP+FN) · Especificidad TN/(TN+FP) · FPR FP/(FP+TN) · F1 = 2PR/(P+R), media armónica (castiga que una de las dos sea baja).
  • Umbral: subirlo → menos FP (sube precision) y más FN (baja recall). Bajarlo → lo contrario. Siempre hay trade-off.
  • Costos asimétricos: FN caro → bajar umbral y priorizar recall (enfermedad, mora, fraude). FP caro → subir umbral y priorizar precision (spam importante, acusar a un inocente). Umbral óptimo t* = C_FP/(C_FP+C_FN).
  • Desbalance: con 3% de positivos, predecir siempre “0” da 97% de accuracy y recall 0. Usar recall, precision, F1, PR-AUC.
  • ROC: TPR vs FPR para todos los umbrales; AUC = 1 perfecto, 0,5 azar, <0,5 al revés; = P(score positivo > score negativo). PR: precision vs recall; mejor con desbalance (base = prevalencia). Average Precision = área bajo la PR.
  • Comparar modelos: A (acc 0,91; recall 0,70) vs B (acc 0,85; recall 0,83): si el FN es caro (diagnóstico), B aunque tenga menos accuracy.
  • Train/val/test: si el modelo rinde 0,99 en train y 0,80 en validación → overfitting. El test no se toca hasta el final.
  • Regresión: MAE = ⅟ₙΣ|y−ŷ| (robusta) · MSE = ⅟ₙΣ(y−ŷ)² (castiga errores grandes) · RMSE = √MSE (unidades de y) · R² = 1 − RSS/TSS.
2 · Árboles de decisión
  • Vocabulario: raíz (primer nodo, contiene todo) · nodo interno (corte X_j < s) · rama (True/False) · hoja (región final; predice moda o media) · profundidad (cortes entre raíz y hoja).
  • Idea: dividir el espacio de predictores en J regiones rectangulares R₁…R_J, distintas y no superpuestas. Toda observación que cae en R_j recibe la misma predicción: moda (clasificación) o media (regresión).
  • Recursive binary splitting: top-down (arranca con todas las observaciones) y greedy (el mejor corte de cada paso, sin mirar adelante). Para cada variable j y punto s se prueba R₁ = {X_j < s}, R₂ = {X_j ≥ s}. Para variables numéricas: puntos medios entre valores consecutivos.
  • Impureza (clasificación): Gini G = 1 − Σp_k² (puro 0, máx binario 0,5) · Entropía D = −Σp_k·log₂p_k (puro 0, máx binario 1) · Error 1 − máx p_k. TGI = Σ(n_h/n)·G_h: gana el corte con MENOR TGI. Con entropía: IG = D(padre) − Σ(n_h/n)·D_h, gana el MAYOR.
  • Regresión: se elige el corte que minimiza RSS = Σ_j Σ_(i∈R_j)(y_i − ȳ_Rj)².
  • Ejemplo de clase (Cool as Ice): TGI(PopCorn) = 0,405 · TGI(Soda) = 0,214 · TGI(Age < 15) = 0,343 → raíz = Soda. Regresión (Age → gasto en cine): RSS 65,71 → 39,30 → 3,00 al agregar cortes.
  • Overfitting: el árbol completo tiene sesgo bajo y varianza alta; el error de entrenamiento siempre baja al agregar hojas, el de CV/test hace una U.
  • Pre-pruning (parar antes): max_depth, min_samples_split, min_samples_leaf, max_leaf_nodes, min_impurity_decrease. Es miope: puede frenar justo antes de un corte muy bueno.
  • Post-pruning: crecer un árbol grande y podarlo minimizando RSS(T) + α·|T| (|T| = hojas). α = 0 → árbol completo; α ↑ → árbol más chico. α se elige por cross-validation (en sklearn: ccp_alpha).
  • Datos faltantes: eliminar, imputar, categoría “faltante”, surrogate splits (CART); sklearn ≥ 1.3 acepta NaN.
  • Ventajas: fáciles de explicar y graficar, imitan decisiones humanas, manejan variables cualitativas sin dummies. Desventajas: menor precisión, poco robustos (alta varianza), fronteras rectangulares. La salida son los ensambles.
  • Lineal vs árbol: relación aproximadamente lineal → gana la regresión; relación no lineal compleja → puede ganar el árbol. Se decide comparando error de test (CV).
3 · Random Forest (bagging + decorrelación)
  • Bagging: promediar árboles entrenados sobre muestras bootstrap (con reemplazo, tamaño n). Baja la varianza.
  • Random Forest: bagging + en cada nodo solo se consideran m < p variables al azar (m ≈ √p en clasificación, p/3 en regresión). Así los árboles se decorrelacionan: si hay un predictor muy fuerte, no todos los árboles empiezan igual.
  • Árboles: profundos, sin podar (bajo sesgo, alta varianza); el promedio baja la varianza. Se construyen en paralelo, independientes. Voto mayoritario (promedio en regresión). Todos pesan igual.
  • Out-of-bag (OOB): P(una observación no sale en un bootstrap) = (1−1/n)ⁿ → 1/e ≈ 0,368 (≈ 1/3). Cada observación se predice con los árboles que no la vieron; error OOB = % mal clasificadas. Aproxima el error de test sin separar datos.
  • Importancia de variables: cuánto baja la impureza (o aumenta el error al permutarla) en promedio.
  • Más árboles no producen overfitting; baja y estabiliza el error.
4 · AdaBoost (boosting)
  • Stumps: árboles de un solo corte (clasificadores débiles). Se entrenan en secuencia: cada uno se concentra en los errores del anterior. Cada stump tiene su propio peso α.
  • Algoritmo: (1) w_i = 1/N · (2) para cada stump: ajustarlo con los pesos (menor Gini ponderado) · ε = suma de pesos de mal clasificados · α = ½ ln((1−ε)/ε) · mal clasificado: w·e^α (sube) · bien clasificado: w·e^(−α) (baja) · normalizar · (3) F(x) = Σ α_b f_b(x), predicción = signo(F).
  • Lectura de α: ε chico → α grande (mucha voz). ε = 0,5 → α = 0 (no mejora al azar, no vota). ε > 0,5 → α < 0 (su voto se invierte). ε = 0 → α infinito (se acota).
  • Tras normalizar, los mal clasificados suman exactamente 1/2.
  • Ejemplo de clase: 8 pacientes, 1 error: ε = 1/8 → α = ½ ln 7 = 0,973; peso del error 0,125·e^0,973 = 0,331 → normalizado 0,5; cada acierto 0,125·e^−0,973 = 0,047 → 0,0714.

5 · Regresión lineal
  • Aprendizaje estadístico: Y = f(X) + ε. Se estima f para predecir (importa la precisión) o inferir (importa entender cómo X afecta a Y). Paramétrico (supone una forma, ej. lineal) vs no paramétrico (flexible, necesita más datos).
  • Simple: Y = β₀ + β₁X + ε. MCO minimiza RSS = Σ(y−ŷ)². β₁ = Σ(x−x̄)(y−ȳ)/Σ(x−x̄)², β₀ = ȳ − β₁x̄.
  • Precisión: SE(β₁) = σ/√Σ(x−x̄)²; IC95% ≈ β₁ ± 2·SE; test t = β₁/SE ~ t(n−2) para H₀: β₁ = 0 (p-valor chico → hay relación).
  • Ajuste: RSE = √(RSS/(n−p−1)) (error típico en unidades de Y) · R² = 1 − RSS/TSS (proporción de varianza explicada; nunca baja al agregar variables) · R² ajustado penaliza variables inútiles.
  • Múltiple: β̂ = (XᵀX)⁻¹Xᵀy. β_j = efecto de +1 en X_j con las demás fijas. Paradoja newspaper: en la simple parece significativo (correlaciona con radio); en la múltiple deja de serlo.
  • Cuatro preguntas: ¿hay relación? → test F = ((TSS−RSS)/p)/(RSS/(n−p−1)) · ¿qué variables? → selección forward/backward/mixta, AIC/BIC/R² aj. · ¿cuán bien ajusta? → RSE, R² · ¿predicción? → el intervalo de predicción es más ancho que el de confianza (suma Var(ε)).
  • Cualitativas: dummies (k−1 para k categorías). Interacciones: X₁·X₂ (sinergia). No linealidad: términos polinómicos o transformaciones.

6 · PCA
  • Para qué: muchas variables cuantitativas correlacionadas → reducir dimensión, visualizar, eliminar multicolinealidad, descubrir factores latentes.
  • Antes: excluir la variable objetivo y los ID; estandarizar z = (x−μ)/σ (PCA sobre la matriz de correlación).
  • Idea: la 1ª componente es la dirección v (con vᵀv = 1) que maximiza la varianza vᵀΣv. Con el Lagrangiano: Σv = λv. Autovector = dirección (loadings); autovalor λ = varianza de la componente. Las componentes son ortogonales (no correlacionadas); cada una maximiza la varianza restante.
  • Varianza explicada: PVE_m = λ_m/Σλ. Con datos estandarizados, Σλ = p. Se retienen componentes hasta ~80–85% acumulado o hasta el codo del scree plot. Máximo p componentes.
  • Scores = datos proyectados Z·V. Loadings = qué variables pesan en cada componente.
  • Ejemplo de clase: 17 variables de tarjetas de crédito; PC1 32,5%, PC2 17%, PC3 14,9%; 6 componentes = 84,5%.
  • 2×2: S = [[4,2],[2,3]] → λ² − 7λ + 8 = 0 → λ = 5,56 y 1,44 (suman la traza 7) → PVE₁ = 79,5%.
  • Límites: solo capta estructura lineal; solo variables cuantitativas; las componentes son menos interpretables; sensible a la escala (por eso se estandariza).
7 · Clustering
  • No supervisado y exploratorio: no hay etiqueta. Hay que decidir: distancia, cuántos grupos, si hay jerarquía, qué distribución, cómo evaluar.
  • K-Means: (1) fijar K (2) centroides iniciales (3) asignar cada punto al centroide más cercano (distancia euclidiana) (4) recalcular centroides como promedios (5) repetir hasta que no cambien. Minimiza WCSS = Σ_kΣ‖x−μ_k‖². TSS = WCSS + BCSS. Grupos esféricos, sensible a escala y outliers, depende de la inicialización.
  • Elegir K: codo (WCSS vs K) · silueta s = (b−a)/máx(a,b) en [−1,1] (a = distancia media a su grupo, b = al grupo vecino más cercano) · ARI si hay partición de referencia (1 perfecto, 0 azar).
  • Jerárquico: aglomerativo (de abajo hacia arriba) o divisivo. Enlaces: Ward (menor aumento de WCSS), Complete (distancia máxima), Average. Se corta el dendrograma a una altura para obtener los grupos; no requiere K de antemano. Costo O(n²) memoria, O(n³) tiempo.
  • DBSCAN: parámetros ε (radio) y MinPts. Punto núcleo (≥ MinPts vecinos en ε), frontera (cerca de un núcleo) y ruido (aislado). Formas arbitrarias, detecta anomalías (fraude), no requiere K; hay que calibrar ε.
  • GMM: P(x) = Σπ_k·N(x|μ_k,Σ_k), ajustada con EM (paso E: responsabilidades; paso M: reestimar). Soft clustering: P(C_k|x_i); grupos elípticos.

8 · Feature Engineering
  • Qué es: transformar y crear variables para mejorar la capacidad predictiva. Suele rendir más que cambiar de modelo.
  • Faltantes: eliminar (pierde información, puede sesgar) · imputar (media/mediana/moda, por grupo, por modelo) · agregar indicador “faltante” (a veces es informativo). Imputar con estadísticos de train (evita leakage).
  • Binning: agrupar numéricas en tramos (edad, antigüedad). Cola larga (monto de siniestros): log o raíz para bajar la asimetría.
  • Escalado: estandarizar o min-max; necesario para K-Means, PCA, KNN, regularización; los árboles no lo necesitan.
  • Codificación: one-hot (pocas categorías) · ordinal (si hay orden) · frequency/target encoding (alta cardinalidad; cuidar leakage).
  • Agregaciones de historiales (suma, media, máx, conteo, recencia, tendencia) · fechas (antigüedad, mes) · ratios e interacciones.
  • Outliers: detectar (IQR, z-score), revisar, winsorizar o transformar.
  • Plan de ML: definir problema y métrica → split train/val/test → limpieza y FE sin leakage → baseline → modelos y CV → evaluar en test → interpretar.

Parte A · El colegio (ML)

🚪 Recibidor: el portero (árbol)

Un portero con un cartel de preguntas sí/no. Cada pregunta parte a la gente en dos. Quiere grupos puros (Gini = 1 − Σp²). Hace overfitting si memoriza a cada persona → hay que podarlo (RSS + α·hojas).

🛋 Living: el bosque (Random Forest)

100 porteros votando. Cada uno vio una muestra distinta (bootstrap) y solo pregunta por algunas variables al azar (m ≈ √p). En paralelo, voto igual → baja la varianza. Un tercio de la gente nunca pasó por cada portero (OOB, 1/e).

🎞 Pasillo: la fila de porteros chiquitos (AdaBoost)

Porteros de una sola pregunta (stumps), en secuencia. A quien el anterior dejó pasar mal le ponen un cartel gigante (peso ↑). Cada uno vota con su peso α = ½·ln((1−ε)/ε). Veredicto = signo(Σα·f). Baja el sesgo.

🕰 Cuarto del reloj al revés: métricas

Reloj que gira al revés: en TP/FP/TN/FN la 1ª letra dice si acerté y la 2ª lo que predije. Cuatro trofeos en orden: accuracy, precision, recall, F1. Una perilla (el umbral) que sube y baja las falsas alarmas.

📐 Cuarto de la recta: regresión

Una regla que pasa por la nube de puntos minimizando los cuadrados de las distancias (RSS). R² es qué parte de la nube explica la recta.

🔦 Estudio de sombras: PCA

17 reflectores sobre la misma estatua: buscás el ángulo de la sombra más larga (PC1), la siguiente a 90° (PC2). Guardás sombras hasta el 80–85%. Σv = λv.

🎉 Patio de la fiesta: clustering

Banderines (K-Means) · árbol genealógico (jerárquico, dendrograma) · ronda de vecinos con uno solo en el fondo = ruido (DBSCAN) · chicos de dos barrios a la vez (GMM, soft).
